用劈尖干涉测量擦镜纸厚度

实验原理与单张厚度计算

实验原理

两块光学平板玻璃一端紧密贴合，形成棱边；另一端放入折成三折的一张擦镜纸，两块玻璃之间形成一层楔形空气薄膜。

单色钠光垂直入射时，一部分光在空气薄膜的上表面（玻璃→空气界面）反射，另一部分光透射进入空气层后，在下表面（空气→玻璃界面）反射。两束反射光频率相同、振动方向一致，可以发生薄膜等厚干涉。下表面的反射产生半波损失，因此两束反射光的光程差为：

Δ = 2d + λ2

其中，d 是该处的空气膜厚度。暗纹满足 2d = kλ（k = 0, 1, 2, …）。相邻两条暗纹对应的空气膜厚度差为 Δd = λ/2。

设相邻暗纹间距为 b、劈尖角为 θ。由于 θ 很小，tan θ ≈ θ = Δdb = λ2b。若棱边至擦镜纸一侧边缘的距离为 L、三折擦镜纸总厚度为 D总，则 tan θ = D总/L。

联立两式，得到 D总 = λL/(2b)。纸折成三层，因此单张擦镜纸厚度为 D测 = D总/3 = λL/(6b)。对多组 b、L 分别计算后取算术平均值。

计算方法

D总 = Lλ2b，D测 = D总3 = Lλ6b

计算时将 λ = 589.3 nm 换算为 0.0005893 mm。每组结果先求三张擦镜纸的总厚度，再除以 3；统计值取有效测量组的算术平均。
